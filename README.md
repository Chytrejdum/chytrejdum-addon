# Chytrej dům – doplněk

Asistent chytré domácnosti pro stávající instalace domácího systému: dům nastavíš rozhovorem, každá změna
jde vrátit. Víc na [chytrejdum.cz](https://www.chytrejdum.cz).

## Instalace

1. V domácím systému otevři **Nastavení → Doplňky → Obchod s doplňky**.
2. Vpravo nahoře **⋮ → Repozitáře** a přidej adresu:
   `https://github.com/chytrejdum/chytrejdum-addon`
3. Najdi **Chytrej dům**, nainstaluj a spusť. Panel **Chytrej dům** se objeví v bočním menu.

Doplněk je k dispozici pro počítače amd64 a aarch64 (64bit ARM).
